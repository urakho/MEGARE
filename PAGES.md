# Публикация игры

Сборка `node tools/build-pages.mjs` создаёт `pages-dist/`:

- `/` — сохранённая версия Git из коммита `cbbd6c0`;
- `/test/` — текущий код проекта на момент сборки.

В обычной версии в разделе промокодов введи `MEGARE-TEST-2026`, чтобы открыть тестовую. Код можно вводить повторно. На GitHub Pages это удобный переход, а не защита: адрес `/test/` доступен напрямую.

При первом входе тестовая версия копирует текущие сохранения в отдельное пространство `megare-test:`. Дальнейшие действия в тестовой версии не меняют сохранения обычной игры. Для возврата открой корень сайта.

После отправки изменений в ветку `main` workflow `.github/workflows/pages.yml` собирает и публикует обе версии. В настройках репозитория GitHub открой **Settings → Pages → Build and deployment → Source** и выбери **GitHub Actions**. Сам каталог `pages-dist/` не нужно добавлять в Git.
